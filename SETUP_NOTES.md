# Setup notes (read before running)

This package contains every hand-authored file from `final-v1-prd.md`,
extracted verbatim (81 files: full SQL schema + RLS, seed data, lib/,
components/, app/ pages, API routes, README, .env.local.example).

Per the PRD itself (Part 2, footnote), the following are **not** hand-authored
and are intentionally NOT included here — they are produced by the scaffold
command in step 3.1, which needs network/npm access this environment doesn't
have:

- `.gitignore`, `next.config.js`, `package.json`, `postcss.config.js`,
  `tailwind.config.ts`, `tsconfig.json` — generated by
  `npx create-next-app@latest peoplepay360 --typescript --tailwind --app --src-dir=false --import-alias "@/*"`,
  then the pinned `npm install` commands in section 3.1 of the PRD.
- `public/` — default Next.js assets from the same scaffold command.

Also not included: `docs/v1-prd.md`. The PRD says this is a literal copy of
the *original* `v1-prd.md` planning document, but only `final-v1-prd.md` was
provided to me — the original file was not available, so I did not fabricate
its contents.

**To finish setup:** run the scaffold command from PRD section 3.1 in an
empty directory, then copy every file from this package on top of the
generated project (overwriting nothing that conflicts, since none of the
hand-authored files collide with scaffold output), then continue from
section 3.1's pinned `npm install` commands.
